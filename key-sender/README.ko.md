# BYD Sub AI 키 전송기 (Key Sender)

**BYD Sub AI** 안드로이드 애플리케이션에 Google Gemini API 키 및 설정을 편리하게 전송할 수 있도록 GGwave 음파 신호를 생성 및 송출하는 Vite + React + TypeScript 웹 애플리케이션입니다.

## 로컬 실행 방법
1. 의존성 패키지 설치:
   ```bash
   npm install
   ```
2. 로컬 개발 서버 시작:
   ```bash
   npm run dev
   ```

## 프로덕션 빌드
웹 호스팅 및 배포를 위한 정적 파일 빌드:
```bash
npm run build
```
