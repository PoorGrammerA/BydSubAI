# BYD Sub AI 사용자 가이드 (User Guide)

본 가이드는 BYD 차량에 탑재된 비공식 음성 비서 에이전트 **'루미(Lumi)'**와 알림음 시스템이 제공하는 주요 기능, 동작 방식 및 실사용법을 일반 사용자 및 운전자 관점에서 쉽게 설명합니다.

---

## 🎙️ 1. 음성 비서 루미 (Gemini Live) 호출 방법

음성 비서 루미는 차량 운행 중 안전하고 빠르게 호출할 수 있도록 다양한 입력 트리거를 지원합니다.

### 1) 핸들(스티어링 휠) 버튼 단축키
- **작동 방법**: 핸들 좌측의 **메뉴(Menu) 버튼을 1초 이내에 빠르게 6회 연속 토글**하여 클릭하면 음성 비서가 즉시 연결되거나 대화가 종료됩니다.
- **음성 안내**: 연결 시작 시 선택한 캐릭터의 시그니처 사운드가 울리며 대화 준비 상태를 알립니다.

### 2) 화면 전환 제어 (홈 런처 연동)
- 홈 화면이나 특정 화면 전환 브로드캐스트(`ENTER_POWER_SCREEN` ➔ `CLOSE_SCREEN_SAVER`)를 감지하여 차량 시동 직후나 화면 전환 시 음성 비서를 자동으로 깨울 수 있습니다.

### 3) 런처 바로가기 숏컷 (One-Tap Shortcut)
- 안드로이드 홈 화면에 캐릭터별 바로가기 아이콘(**루미, 키트, 아스라다**)을 등록하여, 터치 한 번으로 원하는 페르소나 테마로 즉시 대화를 시작할 수 있습니다.

---

## 🧭 2. 내비게이션 길안내 및 장소 검색

SubAI는 독립된 외부 도구 앱과의 연동을 통해 개인정보 보호와 강력한 장소 검색을 동시에 지원합니다.

### 1) 2단계 길안내 파이프라인
1. **장소/POI 검색**: 사용자가 *"근처 맛있는 돈까스집 찾아줘"* 또는 *"강남역 2번 출구 찍어줘"*라고 말하면, 승인된 외부 Tool 앱([**`BydSubAI-KorTools`**](https://github.com/PoorGrammerA/BydSubAI-KorTools))이 카카오 로컬 API를 통해 최신 장소의 위도/경도 좌표(WGS84)를 신속하게 조회합니다.
2. **실시간 내비게이션 시작**: 좌표를 전달받은 SubAI 본체는 차량에 설치된 **네이버 지도(Naver Map)** 또는 **티맵 오토(TMAP Auto)**를 즉시 실행하여 실시간 길안내 모드로 전환합니다.

### 2) 외부 도구 앱 ([`BydSubAI-KorTools`](https://github.com/PoorGrammerA/BydSubAI-KorTools)) 최초 승인
- 한국 장소 검색 기능을 사용하려면 별도 설치된 `BydSubAI-KorTools` APK가 필요합니다.
- SubAI 설정 화면에서 설치된 외부 도구를 감지하면 **최초 1회 사용자 승인** 팝업이 표시됩니다. 승인 완료 후 다음 Gemini Live 세션부터 자동으로 장소 검색이 활성화됩니다.

## 🚗 3. 차량 하드웨어 음성 제어

Gemini Live의 Function Calling을 통해 주행 중 손을 떼지 않고 다양한 차량 기능을 자연스럽게 조작할 수 있습니다.

### 1) 공조기 및 에어컨 제어
- *"에어컨 22도로 켜줘"*, *"바람 세기 3단으로 올려줘"*, *"외기 순환으로 바꿔줘"*, *"앞유리 성에 제거 켜줘"*
- 온도, 풍량, 순환 모드(내기/외기), 성에 제거, 바람 방향(얼굴/발/유리창) 등을 한 번에 제어합니다.

### 2) 시트 및 스티어링 휠 열선/통풍
- *"운전석 엉따 2단계 켜줘"*, *"조수석 통풍 제일 세게 틀어줘"*, *"핸들 열선 켜줘"*
- 운전석/조수석 시트 열선 및 통풍(0~3단계), 스티어링 휠 열선을 음성으로 설정합니다.

### 3) 순차 창문 및 선루프 제어 (Sequential Control)
- *"창문 다 닫아줘"*, *"앞좌석 창문 절반만 열어줘"*, *"선루프 환기 모드로 열어줘"*
- **안전 로직**: BYD 차량 제어 시스템(BCM)의 과전류 차단 현상을 방지하기 위해, 다중 창문 제어 시 **각 창문을 150ms 간격으로 순차 작동**시켜 명령 누락 없이 안정적으로 여닫습니다.

### 4) 배터리 잔량 및 주행가능거리 조회
- *"현재 배터리로 몇 km 갈 수 있어?"*, *"배터리 몇 퍼센트 남았어?"*
- 차량 통계 디바이스(`BYDAutoStatisticDevice`)와 실시간 연동되어 고전압 배터리 잔량(%) 및 잔여 EV 주행가능거리(km)를 정확하게 안내합니다.

## 🎵 4. 음악 및 미디어 앱 연동

- *"멜론에서 최신 인기곡 틀어줘"* ➔ Melon 앱 실행 및 음원 자동 검색
- *"유튜브에서 신나는 드라이브 음악 검색해줘"* ➔ YouTube(공식/ReVanced/NewPipe) 실행 및 검색
- *"카라오케 켜줘"* ➔ 차량용 Stingray 노래방 앱 커스텀 스키마(`stingraykaraoke://`) 연동 실행

## 💡 5. 엠비언트 라이트 음성 싱크 (Voice-to-Ambient)

- **동작 방식**: 루미가 음성으로 답변할 때, 목소리 음량(Volume) 크기에 반응하여 실내 **엠비언트 라이트의 밝기(0~6단계)가 실시간으로 반짝이며 반응**합니다.
- **자동 복구**: 루미가 말을 끝마치면 엠비언트 라이트가 원래의 기본 상태로 부드럽게 복구됩니다.
- **설정**: 설정 화면의 `Gemini Live 대화 시 엠비언트 라이트 연동하기`를 체크하여 활성화할 수 있습니다.

## 🔊 6. 캐릭터 테마 및 저지연 주행 피드백 사운드

차량 센서 데이터와 연동되어 주행 상황을 캐릭터 목소리로 즉각 안내합니다.

### 1) 3종 캐릭터 테마
메인 화면의 '캐릭터 사운드 선택'에서 원하는 테마를 선택할 수 있습니다:
- **루미 (Lumi)**: 친근하고 자연스러운 한국어 구어체 비서 보이스.
- **키트 (KITT)**: 전설적인 전격 Z작전 인공지능 보이스 테마.
- **아스라다 (Asurada)**: 신세기 사이버 포뮬러의 머신 내비게이션 보이스 테마.

### 2) 저지연(`SoundPool`) 주행 상태 피드백
- **기어 변속 안내**: P, R, N, D 변속 시 즉시 상태 음성 안내
- **크루즈 컨트롤**: 어댑티브 크루즈(ACC/ICC) 활성화 및 해제 피드백
- **사각지대 감지 (BSD)**: 사각지대 위험 감지 어시스트 상태 피드백
- **에너지 회생제동 / 주행 모드**: 표준/높음 회생제동 변경, 눈길/일반 노면 감지, 스포츠 모드 전환 안내
- **후방 레이더**: 후진 시 후방 장애물 감지 상태 안내

### 3) ⚠️ 경사로 주차 안전 경고 (Slope Warning)
- 오르막이나 내리막 같은 **경사로(Incline)에서 기어를 P단(주차)으로 변경할 때**, 경사도 센서를 감지하여 차량 밀림 사고를 예방하도록 즉시 경고 음성을 재생합니다:
  - *"경사로 주차 위험이 감지되었습니다. 사이드 브레이크 작동 상태를 확인해 주세요."*

## 📲 7. 음파를 통한 간편 API 키 설정 (Web Key Sender)

차량 터치스크린에서 긴 Gemini API 키를 직접 타이핑할 필요가 없습니다.

1. 스마트폰 웹 브라우저에서 `key-sender` 웹 앱에 접속합니다 (GitHub Pages 배포본 또는 로컬 웹서버).
2. 스마트폰에서 Gemini API 키와 원하는 모델 설정을 입력합니다.
3. 차량에서 SubAI 앱의 키 수신 대기 상태를 확인한 후, 스마트폰에서 **전송 버튼**을 누릅니다.
4. **GGwave 초음파/가청 음파 소리(삐-빅)**가 울리며 3~5초 이내에 차량 내 SubAI로 설정이 무선 전송 및 기기 내 안전 저장소(Android KeyStore)에 암호화 저장됩니다.

## 🛠️ 8. 진단 및 관리 도구 (Power User)

- **로컬 ADB 자가 권한 부여**: 앱 실행 시 `127.0.0.1:5555`를 통해 내부 ADB에 연결하여 진단에 필요한 `READ_LOGS` 권한을 자가 획득합니다.
- **실시간 Logcat 콘솔 뷰어**: SubAI 로그, BYD 차량 SDK 로그 등을 실시간으로 필터링 및 녹화하여 텍스트 파일로 내보내거나 공유할 수 있습니다.
